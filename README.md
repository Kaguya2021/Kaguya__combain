# Xiaomi Bootloader Unlock Sniper 🚀

Многопоточный скрипт-снайпер на Python для автоматической отправки запросов на разблокировку загрузчика Xiaomi (Mi Community) в точный момент открытия лимитов.

## ⚠️ Отказ от ответственности
Автор не несет ответственности за "кирпичи", потерю данных или отказ в разблокировке со стороны Xiaomi. Используйте скрипт на свой страх и риск.

---

## 📌 Требования
* Python 3.8 или выше
* Установленный терминал (например, **Termux** на Android или любая командная строка на ПК)
